REQUISITOS EN EL EQUIPO:
1. Node.js (versión 18 o superior) -> https://nodejs.org/
2. Python (versión 3.10 o superior) -> https://www.python.org/

---------------------------------------------------
PASO 1: EJECUTAR EL BACKEND (Python / FastAPI)
---------------------------------------------------
1. Abre una terminal (PowerShell o CMD).
2. Entra a la carpeta del backend:
   cd backend

3. (Recomendado) Crea un entorno virtual:
   python -m venv venv
   .\venv\Scripts\activate

4. Instala las dependencias:
   pip install -r requirements.txt

5. Inicia el servidor del backend:
   uvicorn main:app --reload --port 8000

* El backend responderá en: http://localhost:8000
* Documentación interactiva de la API: http://localhost:8000/docs

---------------------------------------------------
PASO 2: EJECUTAR EL FRONTEND (React / Vite / Tailwind)
---------------------------------------------------
1. Abre OTRA terminal separada.
2. Entra a la carpeta del frontend:
   cd frontend

3. Instala los paquetes y librerías de Node:
   npm install

4. Inicia el servidor de desarrollo:
   npm run dev

* Abre en tu navegador la dirección indicada en la terminal (por defecto: http://localhost:5173).
